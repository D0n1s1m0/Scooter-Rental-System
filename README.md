# Scooter Rental System (Система аренды самокатов)

## Название проекта
Scooter Rental System — консольное приложение с перспективой развития
в веб-приложение для аренды электросамокатов.

## Назначение
Предоставление пользователям возможности брать электросамокаты в краткосрочную
аренду, управление парком самокатов и станциями, автоматический расчёт
стоимости поездки с учётом скидок. На ПР2 данные сохраняются между запусками
программы в JSON-файлах.

## Целевая аудитория
- **Городские жители и туристы** — пользователи, которым нужен быстрый транспорт
  для коротких поездок.
- **Операторы сервиса** — сотрудники, управляющие парком самокатов и станциями.
- **Администраторы** — управление пользователями, тарифами и аналитикой.

## Описание предметной области
Сервис кикшеринга: пользователь находит ближайший самокат, выбирает дату
и длительность поездки, получает автоматически рассчитанный чек. Система
фиксирует аренды, контролирует статус самокатов (доступен / в аренде /
на обслуживании), ведёт статистику выручки. Самокаты распределены по станциям
и имеют уровень заряда.

## Основные сущности
| Сущность | Описание |
|----------|----------|
| User | Пользователь (клиент, оператор, администратор) |
| Scooter | Электросамокат (модель, заряд, статус, станция) |
| Station | Станция парковки (адрес, координаты, вместимость) |
| Rental | Аренда (самокат, дата, минуты, итоговая стоимость) |
| Tariff | Тариф (цена за минуту, стартовая цена, порог скидки) |
| Payment | Платёж (сумма, метод, статус) |

## Возможности

- просмотр списка самокатов с зарядом, станцией и статусом;
- поиск самоката по подстроке модели;
- отбор самокатов по минимальному заряду;
- сортировка самокатов по заряду (по убыванию);
- просмотр доступных самокатов;
- проверка доступности самоката на выбранную дату;
- создание и отмена аренды;
- автоматический расчёт стоимости поездки;
- скидка 10 % при поездке длительностью более 60 минут;
- статистика: общая выручка по всем арендам;
- сохранение и загрузка данных в JSON-файлах.

## Основные функции

Все перечисленные функции реализованы в виде отдельных функций (`def`),
распределённых по модулям проекта.

**Модуль `scooters.py` — работа с самокатами:**
1. `add_scooter()` — добавление самоката в словарь.
2. `find_scooter()` — поиск самокатов по подстроке модели.
3. `filter_scooters_by_charge()` — отбор самокатов по минимальному заряду.
4. `sort_scooters_by_charge()` — сортировка самокатов по заряду (lambda).
5. `get_scooter_status()` — текстовый статус самоката.
6. `get_available_scooters()` — список доступных самокатов.

**Модуль `rentals.py` — аренды и расчёт стоимости:**
7. `calculate_base_cost()` — автоматический расчёт базовой стоимости поездки.
8. `calculate_discount()` — скидка от оплаты x-количества минут (10 % при > 60 мин).
9. `calculate_total()` — расчёт итоговой стоимости с округлением до 2 знаков.
10. `is_scooter_available()` — проверка доступности самоката на дату.
11. `create_rental()` — создание аренды с расчётом стоимости.
12. `cancel_rental()` — отмена аренды по идентификатору самоката.
13. `get_total_revenue()` — общая выручка (статистика).

**Модуль `storage.py` — сохранение и загрузка данных:**
14. `load_scooters()` / `save_scooters()` — загрузка и сохранение самокатов в JSON.
15. `load_rentals()` / `save_rentals()` — загрузка и сохранение аренд в JSON.

**Модуль `utils.py` — безопасный ввод:**
16. `input_int()` — ввод целого числа с повторным запросом при ошибке.
17. `input_float()` — ввод числа с плавающей точкой.
18. `input_date()` — ввод даты в формате ДД.ММ.ГГГГ.

**Модуль `main.py` — точка входа и меню:**
19. `get_user_name()` — небольшой опрос, чтобы обращаться к человеку по имени.
20. `show_scooters()` — вывод списка самокатов.
21. `show_rentals()` — вывод списка аренд.
22. `show_receipt()` — вывод чека пользователю (переработан из ПР1).
23. `menu()` — главное меню приложения.
24. `main()` — основной сценарий: опрос → меню → действия → сохранение.

**Запланированные функции (будут реализованы на следующих ПР):**
- просмотр карты доступных самокатов (ПР5–ПР7);
- регистрация пользователей и баланс (ПР11);
- управление парком самокатов для операторов (ПР9–ПР10);
- REST API для мобильного клиента (ПР5–ПР9).


## Формат хранения данных

Данные хранятся в JSON-файлах в каталоге `data/`:

- `data/scooters.json` — словарь самокатов, где ключ — идентификатор,
  значение — объект с полями `model`, `charge`, `station`, `status`.
- `data/rentals.json` — список аренд, каждая содержит `scooter_id`,
  `date`, `minutes`, `total`.

Пример `scooters.json`:

```json
{
  "1": {"model": "Xiaomi Mi 3", "charge": 95, "station": "Станция A", "status": "available"},
  "2": {"model": "Ninebot Max", "charge": 60, "station": "Станция B", "status": "available"}
}
```

Пример `rentals.json`:

```json
[
  {"scooter_id": 1, "date": "2026-09-15", "minutes": 100, "total": 477.0}
]
```
