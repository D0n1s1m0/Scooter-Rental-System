# Scooter Rental System (Система аренды самокатов)

## Название проекта
Scooter Rental System — веб-приложение для аренды электросамокатов.

## Назначение
Предоставление пользователям возможности брать электросамокаты в краткосрочную
аренду через веб-интерфейс, управление парком самокатов и станциями,
автоматический расчёт стоимости поездки.

## Целевая аудитория
- **Городские жители и туристы** — пользователи, которым нужен быстрый транспорт
  для коротких поездок.
- **Операторы сервиса** — сотрудники, управляющие парком самокатов и станциями.
- **Администраторы** — управление пользователями, тарифами и аналитикой.

## Описание предметной области
Сервис кикшеринга: пользователь регистрируется в системе, находит ближайший
самокат на карте, сканирует QR-код, начинает поездку. Система фиксирует время
начала и окончания, рассчитывает стоимость по тарифу, списывает средства с
баланса. Самокаты распределены по станциям, имеют уровень заряда и статус
(доступен / в аренде / на обслуживании).

## Основные сущности
| Сущность | Описание |
|----------|----------|
| User | Пользователь (клиент, оператор, администратор) |
| Scooter | Электросамокат (модель, заряд, статус, местоположение) |
| Station | Станция парковки (адрес, координаты, вместимость) |
| Rental | Аренда (пользователь, самокат, время начала/конца, стоимость) |
| Tariff | Тариф (цена за минуту, стартовая цена) |
| Payment | Платёж (сумма, метод, статус) |

## Основные функции

Все перечисленные функции реализованы в файле `main.py`
в виде отдельных функций (`def`).

1. **Небольшой опрос, чтобы обращаться к человеку по имени.**
   При запуске программа запрашивает имя пользователя и использует
   его при выводе результатов и чека.
   Реализация: `get_user_name()`.

2. **Ввод длительности поездки.**
   Программа запрашивает у пользователя количество минут поездки
   и преобразует введённое значение к числовому типу.
   Реализация: `get_trip_minutes()`.

3. **Автоматический расчёт стоимости поездки.**
   Базовая стоимость = плата за разблокировку + минуты × тариф.
   Реализация: `calculate_base_cost()`.

4. **Скидка от оплаты x-количества минут.**
   Если поездка длится дольше заданного порога (60 минут),
   на стоимость применяется скидка 10%.
   Реализация: `calculate_discount()`.

5. **Расчёт итоговой стоимости.**
   Из базовой стоимости вычитается скидка, результат округляется
   до 2 знаков после запятой.
   Реализация: `calculate_total()`.

6. **Вывод чека пользователю.**
   Формирует и печатает чек с разбивкой: разблокировка, поездка,
   скидка, итог.
   Реализация: `print_receipt()`.

7. **Проверка целого количества минут.**
   Определяет, является ли длительность поездки целым числом минут,
   и выводит соответствующее сообщение.
   Реализация: `is_whole_minutes()`.

8. **Основной сценарий работы программы.**
   Объединяет все шаги: опрос → ввод минут → расчёт → вывод чека.
   Реализация: `main()`.

9. **Просмотр карты доступных самокатов.**
   Пользователь видит на карте самокаты со статусом «доступен»,
   их заряд и ближайшие станции.
   Реализация: планируется на ПР5–ПР7 (Django, карты).

10. **Начало и завершение аренды.**
    Пользователь сканирует QR-код, начинается поездка; по завершении
    система фиксирует время и освобождает самокат.
    Реализация: планируется на ПР5–ПР9.

11. **Пополнение баланса и история платежей.**
    Пользователь пополняет баланс и просматривает список своих платежей.
    Реализация: планируется на ПР7–ПР11.

12. **Управление парком самокатов (для операторов).**
    Оператор добавляет, редактирует, снимает с обслуживания самокаты.
    Реализация: планируется на ПР9–ПР10.

13. **REST API для мобильного клиента.**
    Эндпоинты для получения списка самокатов, начала/завершения аренды,
    истории платежей.
    Реализация: планируется на ПР5–ПР9.
