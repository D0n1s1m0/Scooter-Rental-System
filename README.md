# Scooter Rental System (Система аренды самокатов)

Консольное приложение для учёта самокатов и управления их арендой.
В дальнейшем развивается до веб-приложения на Django с базой данных,
пользователями и REST API.

## Название проекта

Scooter Rental System — система учёта самокатов и управления арендой.

## Назначение

Предоставление пользователям возможности брать электросамокаты в краткосрочную
аренду, управление парком самокатов и станциями, автоматический расчёт
стоимости поездки с учётом скидок. Данные сохраняются между запусками
программы в JSON-файлах.

## Целевая аудитория

- **Городские жители и туристы** — пользователи, которым нужен быстрый
  транспорт для коротких поездок.
- **Операторы сервиса** — сотрудники, управляющие парком самокатов
  и станциями.
- **Администраторы** — управление пользователями, тарифами и аналитикой.

## Описание предметной области

Сервис кикшеринга: пользователь регистрируется в системе, находит ближайший
самокат на карте, сканирует QR-код, начинает поездку. Система фиксирует время
начала и окончания, рассчитывает стоимость по тарифу, списывает средства
с баланса. Самокаты распределены по станциям, имеют уровень заряда и статус
(доступен / в аренде / на обслуживании).

## Основные сущности

| Сущность | Описание |
|----------|----------|
| User | Пользователь (клиент, оператор, администратор) |
| Scooter | Электросамокат (модель, заряд, статус, местоположение) |
| Station | Станция парковки (адрес, координаты, вместимость) |
| Rental | Аренда (пользователь, самокат, время начала/конца, стоимость) |
| Tariff | Тариф (цена за минуту, стартовая цена) |
| Payment | Платёж (сумма, метод, статус) |

## Основные функции

Все реализованные функции оформлены отдельными `def` и распределены
по модулям проекта.

### Реализовано на ПР1 и ПР2

1. **Небольшой опрос, чтобы обращаться к человеку по имени.**
   При запуске программа запрашивает имя и использует его в чеке.
   Реализация: `get_user_name()` в `main.py`.

2. **Ввод длительности поездки.**
   Запрос количества минут и преобразование к числу.
   Реализация: `input_float()` в `utils.py`, `input_int()` в `utils.py`.

3. **Автоматический расчёт стоимости поездки.**
   Базовая стоимость = плата за разблокировку + минуты × тариф.
   Реализация: `calculate_base_cost()` в `rentals.py`.

4. **Скидка от оплаты x-количества минут.**
   Если поездка длится дольше 60 минут — скидка 10%.
   Реализация: `calculate_discount()` в `rentals.py`.

5. **Расчёт итоговой стоимости.**
   Из базовой стоимости вычитается скидка, результат округляется
   до 2 знаков.
   Реализация: `calculate_total()` в `rentals.py`.

6. **Вывод чека пользователю.**
   Формирует и печатает чек с разбивкой.
   Реализация: `show_receipt()` в `main.py`.

7. **Добавление самоката.**
   Добавление новой записи в словарь самокатов с автоидентификатором.
   Реализация: `add_scooter()` в `scooters.py`.

8. **Поиск самоката по модели.**
   Поиск по подстроке в названии модели.
   Реализация: `find_scooter()` в `scooters.py`.

9. **Фильтрация самокатов по заряду.**
   Отбор самокатов с зарядом не меньше заданного (генератор).
   Реализация: `filter_scooters_by_charge()` в `scooters.py`.

10. **Сортировка самокатов по заряду.**
    Сортировка по убыванию заряда через `lambda`-функцию.
    Реализация: `sort_scooters_by_charge()` в `scooters.py`.

11. **Определение статуса самоката.**
    Возврат текстового статуса (доступен / в аренде / на обслуживании).
    Реализация: `get_scooter_status()` в `scooters.py`.

12. **Список доступных самокатов.**
    Возврат идентификаторов самокатов со статусом «доступен».
    Реализация: `get_available_scooters()` в `scooters.py`.

13. **Проверка доступности самоката на дату.**
    Запрет повторной аренды на ту же дату.
    Реализация: `is_scooter_available()` в `rentals.py`.

14. **Создание аренды.**
    Формирование записи аренды с расчётом стоимости.
    Реализация: `create_rental()` в `rentals.py`.

15. **Отмена аренды.**
    Удаление записи аренды по идентификатору самоката.
    Реализация: `cancel_rental()` в `rentals.py`.

16. **Статистика: общая выручка.**
    Сумма всех платежей по арендам.
    Реализация: `get_total_revenue()` в `rentals.py`.

17. **Сохранение и загрузка данных в JSON.**
    Работа с файлами через контекстный менеджер `with`.
    Реализация: `load_scooters()`, `save_scooters()`, `load_rentals()`,
    `save_rentals()` в `storage.py`.

18. **Безопасный ввод.**
    Обработка ошибок при вводе целого, дробного числа и даты.
    Реализация: `input_int()`, `input_float()`, `input_date()` в `utils.py`.

19. **Основной сценарий работы программы.**
    Меню и вызов функций проекта в цикле.
    Реализация: `main()`, `menu()` в `main.py`.

### Планируется на следующих этапах

    Реализация: ПР5–ПР9.

    Реализация: ПР7–ПР11.

    Реализация: ПР9–ПР10.

24. **REST API для мобильного клиента.**
    Реализация: ПР5–ПР9.
