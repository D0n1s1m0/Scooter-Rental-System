# Scooter Rental System (Система аренды самокатов)

## Название проекта
Scooter Rental System — веб-приложение для аренды электросамокатов.

## Назначение
Предоставление пользователям возможности брать электросамокаты в краткосрочную
аренду через веб-интерфейс, управление парком самокатов и станциями,
автоматический расчёт стоимости поездки.

## Целевая аудитория
- **Городские жители и туристы** — пользователи, которым нужен быстрый транспорт
  для коротких поездок.
- **Операторы сервиса** — сотрудники, управляющие парком самокатов и станциями.
- **Администраторы** — управление пользователями, тарифами и аналитикой.

## Описание предметной области
Сервис кикшеринга: пользователь регистрируется в системе, находит ближайший
самокат на карте, сканирует QR-код, начинает поездку. Система фиксирует время
начала и окончания, рассчитывает стоимость по тарифу, списывает средства с
баланса. Самокаты распределены по станциям, имеют уровень заряда и статус
(доступен / в аренде / на обслуживании).

## Основные сущности
| Сущность | Описание |
|----------|----------|
| User | Пользователь (клиент, оператор, администратор) |
| Scooter | Электросамокат (модель, заряд, статус, местоположение) |
| Station | Станция парковки (адрес, координаты, вместимость) |
| Rental | Аренда (пользователь, самокат, время начала/конца, стоимость) |
| Tariff | Тариф (цена за минуту, стартовая цена) |
| Payment | Платёж (сумма, метод, статус) |

## Основные функции
1. Регистрация и авторизация пользователей.
2. Просмотр карты доступных самокатов.
3. Начало и завершение аренды.
4. Автоматический расчёт стоимости поездки.
5. Пополнение баланса и история платежей.
6. Управление парком самокатов (для операторов).
7. REST API для мобильного клиента.
8. Административная панель со статистикой.
